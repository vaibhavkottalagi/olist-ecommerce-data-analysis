# Olist E-Commerce Data Analytics Project

## 📌 Executive Summary
An end-to-end data analytics study on Brazil's largest marketplace dataset (Olist). This project covers raw data extraction, SQL relational modeling, multi-tool dashboard development (Excel, Power BI, Tableau), and executive reporting to evaluate sales performance, delivery logistics, and customer satisfaction.

## 🛠️ Tech Stack & Skills Demonstrated
- **SQL (MySQL Workbench / BigQuery):** Complex queries, CTEs, Window Functions, Aggregations, Data Cleaning.
- **Microsoft Excel:** Advanced Formulas, Power Query, Pivot Tables, Dynamic Visual Dashboards.
- **Power BI:** Data Modeling (Star Schema), DAX Measures, Interactive Dashboards.
- **Tableau:** Visual Analytics, Interactive Story Points, Geospatial Mapping.
- **PowerPoint:** Executive Business Presentation & Storytelling.

## 💡 Key Business Insights
1. **Logistics Impact:** Orders with delivery delays showed a **60% drop** in customer review ratings.
2. **Top Product Categories:** Health & Beauty and Bed/Bath/Table generated over **25%** of total revenue.
3. **Payment Trends:** Over **70%** of transactions were completed via credit card, averaging **3.2 installments**.
